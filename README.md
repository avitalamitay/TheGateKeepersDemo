# Welcome to The Gatekeepers Portal!

## Overview
A custom, fully responsive Hebrew (RTL) web portal designed and built for an active, ongoing interactive live-action (LARP) campaign. Instead of scattering logistics, lore, and rules across endless messages and documents, the site serves as a centralized operational and onboarding hub for participants, delivering the same complete experience across both desktop and mobile devices.

[Visit the Live Site Here!](https://avitalamitay.github.io/TheGatekeepers/)

## Key Features
* *Centralized Operations & Onboarding Hub:* Consolidates everything participants need in one accessible place:
  * *Logistics & Schedule:* Full annual session calendar, location updates, dietary/allergy accommodations, and payment guidelines.
  * *Discord Onboarding:* A step-by-step guide explaining server categories, private thread creation, and nickname formatting.
  * *Safety & Mechanics:* Dedicated pages for community safety protocols ("Lines & Veils"), consent-based mechanics, and world-building lore.
* *Live Session Countdown:* Dynamically calculates and displays a real-time countdown to the next scheduled live session.
* *Character Randomizer:* An interactive generator button built to help players brainstorm character concepts on the fly.
* *Hidden Easter Egg:* An interactive in-world secret tucked into the site that unlocks a hidden welcome letter for attentive visitors.
* *Responsive RTL UI/UX & Theme Toggle:* Features a quick-jump navigation menu to relevant sections across the site, a Light/Dark mode toggle, and a clean card-based layout designed for comfortable Hebrew reading on both desktop and mobile.

## Technologies used and Integrations
* *Frontend:* HTML5, CSS3, Vanilla JavaScript.
* *Hosting:* GitHub Pages.
* *Community Integration:* Structured onboarding flow connected to the campaign's Discord server.
